# RemPlanner Skill

Один скилл для Codex: планировка и инженерные листы RemPlanner с проверяемыми источниками требований РФ, настройками конкретного проекта и read-only диагностикой геометрии.

**Не готовый проект электрики/сантехники и не сертификат соответствия.** Скилл помогает находить применимые правила и выявлять пробелы. Он не знает обмеры, ввод, заземление или модель бойлера, пока эти данные не предоставлены и не проверены.

## Что внутри

- Работа с мебелью, электроточками/кабелями/щитом, водой/канализацией, бойлером, AC-подготовкой, вентиляцией и мокрыми зонами.
- [Реестр источников](remplanner-browser/references/rules.md) с проверенным срезом, изменениями и явными пробелами. Скилл требует перепроверки актуальности перед нормативным решением.
- Разделение требований документа, рекомендаций, инструкций конкретного прибора и пожеланий заказчика.
- Проверки целых рёбер, препятствий, графов, якорей и заданных высот/отступов на **нормализованном JSON**. Нативные `.plan` автоматически не разбираются и не исправляются.
- Сохранение, повторное открытие и проверка штатного альбома RemPlanner; без подмены экспорта самостоятельно нарисованным PDF.

## Установка в Codex

Скопируйте папку `remplanner-browser` целиком в каталог навыков Codex, обычно `~/.codex/skills/`. Если такая папка уже существует, сначала сравните содержимое и сохраните резервную копию вне каталога обнаружения навыков. Не перезаписывайте пользовательские изменения вслепую.

Можно попросить установленный Skill Installer установить `remplanner-browser` из этого репозитория. Сам скилл не требует токенов, `.env`, платных API или отдельного MCP. Для изменения проекта нужен разрешённый инструмент управления браузером и пользовательский вход в RemPlanner. Доступные функции зависят от аккаунта/подписки.

После обновления перечня навыков:

```text
Используй $remplanner-browser. Проверь мой текущий план и исходные
чертежи, сохрани мебель и бюджет. Исправь подтверждённые ошибки,
а неизвестные монтажные условия вынеси в отдельный список.
```

Для кухонного бойлера укажите тип/модель, объём, мощность и назначение, если они уже известны. Отсутствие данных должно оставлять резерв, а не порождать выдуманный прибор.

## Диагностика и тесты

Требуется Python 3.10+; сторонние библиотеки не нужны.

```sh
python3 -m unittest discover -s tests -v
python3 remplanner-browser/scripts/audit_geometry.py normalized.json
```

Формат и полный пример: [configuration.md](remplanner-browser/references/configuration.md). Код выхода `0` — только прохождение переданных геометрических проверок, `1` — FAIL, `2` — UNKNOWN/неверный вход. Входной файл не изменяется. Проверка зон ванной, сечений, УДТ, уклонов, конструкций, доступа в 3D и фактического монтажа **не автоматизирована этим скриптом**.

[Поведенческие сценарии](tests/SCENARIOS.md) проверяют решения агента отдельно от кода. Ни тесты, ни несколько субагентов не заменяют квалифицированного специалиста и необходимые измерения.

## Актуальность, приватность и границы

Срез реестра — 5 сентября 2026 года; это не обещание бессрочной актуальности. Для изменения правила нужны первичный текст, точный пункт/редакция, применимость и регрессионный сценарий. Не превращайте популярные размеры 30/110/150 см в универсальные нормы ПУЭ.

Личные планы, аккаунты, ссылки с токенами, чертежи и скачанные книги/PDF в репозиторий не входят. Нормативные документы и руководства принадлежат правообладателям; здесь ссылки и краткие адресные указания, а не копии изданий.

Газ, несущие расчёты, согласование перепланировки, производственная аспирация и допуск к монтажу требуют отдельной предметной проверки. Нельзя заключать «квартира соответствует всем нормам» по нескольким пройденным проверкам.

Независимый неофициальный проект, не продукт и не консультация компании RemPlanner. Лицензия MIT — только на собственный код и текст репозитория.
